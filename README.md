# Napell RWA

RWA / STO structuring concept site for Napell's aeroponic coffee assets — data-asset securitisation, PRC data-export compliance path, Cayman SPV wrapper, and SFC-regulated issuance in Hong Kong, China.

**Live:** https://erikcywong.github.io/Napell.rwa/

## What's in here

| Section | Content |
|---|---|
| `#overview` | Data assetisation → securitisation thesis |
| `#compliance` | PRC data-export path (classification → security assessment → approval) |
| `#sto-issue` | 5 issuance steps: SPV, valuation/DD, structure & docs, SFC filing, issuance & listing |
| `#structure` | Cayman vs Hong Kong SPV comparison + typical stack |
| `#process` | 7-stage end-to-end runbook, 6–9 months |
| `#contact` | Advisory intake form (static, no backend) |

Plus [`BUSINESS-MODEL.md`](./BUSINESS-MODEL.md) — critical review of the model behind the page.

## Stack

Single-file static page. Tailwind CSS (CDN), Chart.js 4 (CDN), Font Awesome 4.7 (CDN). No build step, no dependencies, no backend.

```bash
python -m http.server 8080    # then open http://localhost:8080
```
