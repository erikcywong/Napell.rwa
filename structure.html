04 / Structure

收益分成票据，加一份采购权

只给收益率，这是一张高息债；再给折价拿货权，买家才会从「加密基金」换成「产业买家」。后者定价理性、持有期长、不要求退出通道。

04.1 / Architecture

现金流、核证、担保，三层并行

每一层都有独立的对手方与文件。任何一层缺失，结构就不成立。

庄园买方 · Estates 咖啡产区补种需求方，独立法人，非关联方
种苗供货 + 组培授权合同 单价 · 数量 · 验收标准 · 按株提成 · 违约条款。这是底层资产本体
Napell 运营主体（境内 / 香港） 履约方：基地运营、出货、开票、收款
收益权转让协议 跨境法律文件：目的、范围、存储地、再转移限制、应急处置
开曼 SPV · 破产隔离 持有合同债权与收益权；与运营主体风险隔离；发行主体
收益分成票据 · 8–12% + 优先采购权 按季分配 · 摊还安排 · 折价采购额度 · 转让受限
专业投资者 · PI only 产业买家 / 家族办公室 / 气候与影响基金
旁路 / PROOF

核证层（不承担现金流）

IoT 采集 → 第三方核证 → 季度复核报告。作用：证明履约真实、支撑溢价、满足存续披露。数据本身不入 SPV 资产池。

旁路 / SECURITY

担保层（提供下行保护）

在库生豆仓单质押 + 应收账款质押 + 回款账户监管。三条同时设，才能在违约时有可处置标的。

04.2 / Terms

核心条款框架

区间为结构设计的目标值，最终以发行文件为准。

条款设定设计理由
票息8–12% p.a.固定 6% + 超额收益分成，把上行留给投资人，下限由合同现金流覆盖
期限24–36 个月与种苗交付周期 + 庄园付款账期匹配，避免期限错配
摊还按季付息
到期还本		季度现金流与出货批次对齐，减少现金拖拽
优先采购权额度 = 认购额
折价 5–8%		产业买家的真实诉求是供应保障；这项权利是他们入场的主要理由
担保仓单质押
+ 应收质押
+ 账户监管		违约时可处置标的；没有担保层的收益权票据等同无抵押信用债
财务契约DSRA ≥ 1 期
集中度 < 25%		债务偿还准备金 + 单一债务人上限，防止单点失效
违约处置90 天加速到期
质押物处置		先处置仓单，再追索应收，最后追索运营主体
信息披露季度核证报告
年度审计		核证数据 + 出货台账，投资人可自行核对
转让限制仅限 PI
发行人同意		不制造虚假流动性，不做公开宣传
最低认购HK$100 万控制持有人数量，降低存续管理成本
以上为结构设计参考，非任何具体发行的条款。实际条款须由持牌机构、法律顾问与审计师共同确定。
04.3 / Why the option

为什么加采购权

同一张票据，加不加这项权利，买家池完全不同。

只有票息票息 + 采购权
买家：高息债基金、加密基金买家：贸易商、烘焙商、产业资本
关注：票息、抵押率、退出关注：货源、品质、价格、稳定性
要求二级流动性持有到期，长期合作
议价：要更高的票息议价：要更大的采购额度

04.5 / Risks

风险因素（写给投资人看的版本）

以下每一条都会写进发行文件，不做淡化处理。

01 — 履约

产量与存活率不达预期

生物资产受病害、环境失控、操作失误影响。缓解：分批交付、存活率保证条款、保险。

02 — 集中度

单一庄园违约

付款方集中会放大单点风险。缓解：债务人分散上限、DSRA、仓单质押。

03 — 监管

出境与发行双重审批

任一环节口径变化都会延后时间表。缓解：分档申报、预留 3 个月缓冲。

04 — 流动性

无二级市场

持有人可能持有至到期，期间无法退出。这一点不做任何暗示性承诺。

05 — 汇率与跨境

资金汇回受阻

付汇、分配均需银行合规审查。缓解：发行前完成路径测试。

06 — 技术

代币与账务不一致

链上记录与 SPV 账册可能偏离。缓解：以 SPV 账册为准，代币仅作权益凭证。
